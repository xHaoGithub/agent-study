# 指定网页与课程映射：AI Agent 入门

## 来源与使用方式

- 指定来源：[AI Agents in Depth · 第 1 章 Agent 基础知识](https://bojieli.github.io/ai-agent-book/book/chapter1/#agent)
- 本课程访问日期：2026-07-28
- 使用原则：阅读原网页获得完整论述；本文只做概念导航、项目映射和审核设计，不替代原文。
- 时效规则：网页中的具体模型、版本、框架和性能描述可能变化，涉及选型时必须重新核验。

## 本课程纳入的知识主线

1. Agent 的最小组成：模型负责决策，上下文提供可见信息，工具提供行动能力。
2. 上下文由稳定规则和不断增长的任务轨迹共同构成；缺少工具结果或历史会破坏闭环。
3. 工具调用不是模型直接执行代码，而是“模型提出调用—应用执行—结果回传—模型继续判断”。
4. ReAct 把思考、行动和观察串成循环，直到完成、失败或触发停止条件。
5. 生产级 Harness 在上下文和工具之外增加约束、验证与纠正。
6. 工程关注范围从 Prompt 扩展到上下文、Harness，再到跨轮次的 Loop。
7. 构建时优先简单、透明和容易被模型正确使用的工具接口。
8. Workflow 用固定路径换取控制，自主 Agent 用动态路径换取适应性，实际系统可以混合。
9. 护栏应覆盖输入、执行和输出；高风险或连续失败时引入人工。
10. 模型变强不会自动消除权限、审计、恢复、评测和业务边界。

## U01 审核任务

完成指定网页第 1 章阅读并运行项目后，学习者需要：

1. 不看资料，用自己的话画出 Agent 的组成和执行循环。
2. 指出本项目中哪些部分属于模型，哪些属于 Harness。
3. 解释为什么本项目不是纯固定工作流，也不是完全自主 Agent。
4. 找到一个约束、一个验证和一个纠正机制；如果当前缺少纠正机制，要如实指出。
5. 面对“自动退款 Agent”新场景，说明哪些步骤固定、哪些可交给模型、哪里必须人工确认。

审核使用 `learning/LEARNING_RECORD.md` 的统一量表。通过 U01 后，才在学习记录中标记完成。
