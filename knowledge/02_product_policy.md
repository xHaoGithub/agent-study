# 事实与决策

- 客户反馈、访谈记录和埋点数据属于输入证据，不等于已经确认的产品需求。
- 方案只有在产品评审会上由产品负责人确认后，才能标记为“最终决策”。
- 单个客户的强烈意见可以触发调研，但不能单独证明需求具有普遍性。

# 优先级

- RICE 只用于形成暂定排序，不替代负责人决策。
- reach、impact、confidence、effort 四项中任一项没有依据时，不得伪造数值。
- 高风险数据写入能力必须具备权限校验、人工确认、操作日志和失败回滚方案。

# 上线门槛

- 新 Agent 上线前必须通过离线 Golden Dataset 回归测试。
- 核心指标至少包括任务完成率、引用准确率、工具调用成功率、响应时延和单任务成本。
- 涉及外部写操作时，必须单独统计人工拒绝率与误操作率。
